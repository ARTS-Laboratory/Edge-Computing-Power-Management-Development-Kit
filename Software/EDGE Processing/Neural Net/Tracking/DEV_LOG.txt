## E009 — Multi-Recording PPG CNN

**Input:** PPG only  
**Train:** 8 datasets / 29,124 windows  
**Validation:** 2 datasets / 9,499 windows  
**Test:** 2 datasets / 10,469 windows  
**Seeds:** 1–5  
**Training:** Minibatches + validation-based early stopping

**Result:**
- Best epoch: 29.4 ± 3.4
- Train MAE: 10.72 ± 0.85 BPM
- Validation MAE: 16.21 ± 0.64 BPM
- Test MAE: 14.16 ± 1.23 BPM
- Test RMSE: 18.32 ± 1.22 BPM
- Correlation: 0.669 ± 0.007
- Bias: +8.90 ± 2.32 BPM

**Motion MAE:**
- Low: 12.63 ± 1.32 BPM
- Medium: 14.53 ± 1.36 BPM
- High: 15.31 ± 1.06 BPM

**Outcome:** Larger training set reduced variability and bias. Error increased with motion level.

# Current Best Model

**Model:** PPG-only CNN v0.1

**Five-run test performance:**
- MAE: 14.16 ± 1.23 BPM
- RMSE: 18.32 ± 1.22 BPM
- Correlation: 0.669 ± 0.007

**Current Findings:**
- CNN outperformed DenseNN for PPG-only HR estimation.
- Adding raw XYZ as direct predictive input did not improve Dense or CNN performance.
- PPG-only error increased with motion.

**Status:** Development baseline. Methodological choices remain under review.
