# PATCH Neural Network — Decisions Made

Finalized methodological decisions. Each decision should include its justification and supporting citation when applicable.

---

## D001 — Native Sampling Rate

**Decision:** Use PATCH's native 50 Hz PPG sampling rate.

**Reason:** Avoids unnecessary resampling of PATCH data.

**Support:** PATCH acquisition configuration.

---

## D002 — Recording-Level Data Split

**Decision:** Keep each complete PA recording within only one dataset partition.

**Reason:** 15-second windows overlap, so splitting windows from the same recording could cause data leakage.

**Support:** Citation needed.

---

## D003 — Train / Validation / Test Separation

**Decision:** Use separate recordings for training, validation, and testing.

**Reason:** Training updates model weights, validation selects the model, and testing evaluates the finalized model.

**Support:** Citation needed.

---

## D004 — Multiple Training Runs

**Decision:** Train each model using five fixed seeds: 1–5.

**Reason:** Measures variability caused by model initialization and training.

**Reporting:** Mean ± sample standard deviation.

**Support:** Citation needed.

---

## D005 — Actiheart Zero HR

**Decision:** Exclude Actiheart values reported as 0 BPM from HR-label calculation.

**Reason:** Observed as missing/dropout measurements in the PA datasets.

**Support:** Actiheart documentation/citation needed.

## D006 — Sequential Window Generation

**Decision:** Generate 15-second candidate windows with a 1-second hop.

**Implementation:** Consecutive candidate windows overlap by 14 seconds.

**Note:** This is the current model-development windowing method and does not define the final embedded inference schedule.

---

## D007 — Embedded Inference Separate from Training Windowing

**Decision:** Do not assume the NN training-window schedule defines the embedded implementation.

**Reason:** The current 1-second-hop windows are used for model development. Final embedded processing must account for PATCH memory and processing constraints.
